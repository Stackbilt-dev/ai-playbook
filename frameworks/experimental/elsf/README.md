# ELSF — Enhanced Logic-Based Synergistic Framework

> **Status: experimental checklist.** ELSF contains a useful distinction between logical consistency and pattern-based evidence, but the repository does not include a formal grammar, proof system, executable logic engine, confidence model, or benchmark. Review the [experimental maturity card](../README.md#elsf-maturity-card) before use.

The original framework note is preserved in [elsf-framework.md](elsf-framework.md).

## Testable Kernel

Use ELSF as a claim-audit hypothesis:

1. Extract claims, constraints, relations, and validation criteria.
2. Label each claim as observed fact, inference, forecast, preference, or obligation.
3. Record provenance and time bounds.
4. Check contradictions and unmet constraints.
5. Evaluate supporting patterns separately from logical consistency.
6. Abstain or escalate when evidence cannot resolve the conflict.

This sequence is not formal logic until its representation and inference rules are specified. For a practical version of the distinction, see [Claims Before Conclusions](../../../field-guides/the-shape-of-judgment/chapters/04-claims-before-conclusions.md).
